# Project template

Capstone project: a multi-page website built with HTML, SASS and TypeScript.

## Prerequisites

- [Node.js](https://nodejs.org/) 22.13 or newer, which includes npm

## Setup and run

The project runs with two commands:

1. Install the dependencies:

   ```bash
   npm install
   ```

2. Compile the project and launch it:

   ```bash
   npm run dev
   ```

`npm run dev` compiles the SASS and TypeScript files, starts a local server and opens the home page in your browser (usually at `http://localhost:3000/src/index.html`). While it runs, the files are recompiled and the page reloads whenever you save a change. Press `Ctrl+C` to stop it.

## Compilation

Pages load their styles and scripts from the `dist` folder, so they only work after compilation. `npm run dev` does this for you.

To compile without launching the project, run:

```bash
npm run compile
```

### SASS

`npm run compile:styles` compiles every `.scss` file in `src/scss` into a `.css` file in `dist/css`, keeping the same folder structure. Files whose names start with an underscore (partials such as `_buttons.scss`) produce no CSS of their own. They only reach the output when another file loads them with `@use`.

### TypeScript

`npm run compile:scripts` type-checks every `.ts` file in `src/ts` and compiles it into a `.js` file in `dist/js`. The settings are in `tsconfig.json`. Type errors are printed in the terminal.

Each page loads `main.js` plus its own script (for example `home.js`) as an ES module. When one file imports another, write the import with a `.js` extension, because that is the file the browser loads:

```ts
import { formatPrice } from "./utils.js";
```

### Generated files

The `dist` folder is generated, so it is not committed to Git. Edit the files in `src`, not the ones in `dist`.

## Scripts

| Script | What it does |
| --- | --- |
| `npm run dev` | Compiles everything, then watches for changes and serves the site |
| `npm run build` | Same as `npm run compile` |
| `npm run compile` | Compiles styles and scripts once |
| `npm run compile:styles` | Compiles SASS only |
| `npm run compile:scripts` | Compiles TypeScript only |
| `npm run watch` | Recompiles styles and scripts on every change, without a server |
| `npm run serve` | Serves the site and reloads the browser on changes, without compiling |
| `npm run lint` | Checks scripts and styles (runs both lint scripts below) |
| `npm run lint:scripts` | Compiles TypeScript, then checks the generated `.js` files in `dist/js` with ESLint |
| `npm run lint:styles` | Checks every `.scss` file in `src/scss` with Stylelint |

## Linting

- **ESLint** (`eslint.config.mjs`) uses the recommended JavaScript rules plus `eqeqeq`, `no-var`, `prefer-const` and `no-console`. It checks the compiled `.js` files, because the project uses TypeScript 7, which ESLint's TypeScript parser does not support yet. Fix any reported problem in the matching `.ts` file in `src/ts`.
- **Stylelint** (`.stylelintrc.json`) uses `stylelint-config-standard-scss`, with BEM class names (`block__element--modifier`) and `rgba()` colors allowed.

## Project structure

```text
src/
  index.html   Home page
  html/        Other pages
  ts/          TypeScript source files
  scss/        SASS source files (main.scss is the entry point)
  assets/      Icons and static data
dist/          Generated by compilation
  css/         Compiled CSS
  js/          Compiled JavaScript
```
